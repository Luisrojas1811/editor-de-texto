# Editor de Texto

Editor de texto simple hecho con Python y tkinter.

## ¿Qué hace?

Abre una ventana donde podés escribir texto, abrir archivos
`.txt` existentes y guardar tu trabajo en un archivo nuevo.

## Tecnologías

- `tkinter` — interfaz gráfica (incluido en Python)
- `filedialog` — abre el explorador de archivos de Windows
  (incluido en tkinter)

## Uso

```bash
python main.py
```

Se abre una ventana con dos botones:

- **Abrir** — abre un archivo `.txt` existente
- **Guardar** — guarda el texto en un archivo `.txt`
